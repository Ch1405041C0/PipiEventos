# Reglas para agentes de Pipi Eventos

- Usar estas instrucciones solo para trabajo de desarrollo del proyecto.
- Consultar el README y la documentación existente antes de proponer cambios de arquitectura.
- Guardar especificaciones aprobadas en `docs/designs/`; usar `.dev/docs/` solamente para borradores locales.
- No modificar integraciones de pago, WhatsApp ni datos reales sin una decisión explícita y pruebas apropiadas.
- No exponer secretos, números de teléfono reales ni datos de clientes en código, documentación o revisiones.
- No presentar una revisión como exhaustiva sin pruebas y evidencia verificable.
